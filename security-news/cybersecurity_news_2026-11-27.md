# 2026年11月27日 サイバーセキュリティニュースまとめ

## 主要ポイント

* VMware製品群（ESX、vCenterなど）にCVSS 9.8の脆弱性を含む計23件の脆弱性が公表され、リモートコード実行や認証回避のリスクが指摘されています。
* Drupalにおいて前回の緊急パッチ適用後も一部サイトで乗っ取りが可能な「高クリティカル」脆弱性が判明し、すでに悪用が確認されたため侵害調査が呼びかけられています。
* SolarWinds Serv-U、HPE AirWave、組み込みLinuxのBusyBoxといったインフラ・運用基盤ソフトウェアにおいて、認証回避やroot権限昇格を許す深刻な脆弱性が相次ぎ報告されました。

## 仮想化およびインフラ基盤の脆弱性

BroadcomはVMware ESXやvCenterなどにおいて、メモリ破壊によるコード実行やディレクトリサービスの認証回避（CVSS 9.8）など計23件の脆弱性を公開しました。また、組み込みLinux向けユーティリティ「BusyBox」のtftpd機能にパストラバーサル（CVSS 9.8/9.3）が判明し、パッチ未適用の環境で外部ファイルの不正読み書きにつながるおそれがあります。

## ネットワーク・ファイル転送管理のセキュリティ対応

SolarWindsは「Serv-U 2026.4」をリリースし、Linuxでのroot権限昇格や競合状態による不正ファイルアクセスなど「クリティカル」9件を含む計18件の脆弱性を修正しました。HPEのネットワーク管理製品「AirWave」でも、認証不要のリモートコマンド実行（CVSS 9.8）や認証回避を含む15件（クリティカル3件）への対応が行われました。

## Webアプリケーションにおける不完全な修正と悪用

Drupalでは、2026年11月18日に修正されたインストーラの脆弱性対策が不十分であり、インストール不完全など特殊な状態のサイトで認証なしのサイト乗っ取りが可能な「CVE-2026-136716」が判明しました。重要度は「高クリティカル」と評価され、すでに実際の悪用事例が確認されているため早急な侵害調査が求められています。

# 2026年11月27日 サイバーセキュリティニュース詳細

## ニュース紹介

### 1. 「ESX」「vCenter」などVMware製品に23件の脆弱性

Broadcomは現地時間2026年11月24日、VMware製品に関するセキュリティアドバイザリ（VMSA-2026-0011）を公開し、CVEベースで計23件の脆弱性に対処しました。重要度は「クリティカル（Critical）」が4件、「重要（Important）」が6件、「中（Moderate）」が10件、「低（Low）」が3件となっています。
特に「VMware ESX」のI/Oフィルタサービスにおける域外メモリ書き込み（CVE-2026-123910）や解放後メモリ使用（Use-After-Free: CVE-2026-123911）は、リモートからホスト上で任意のコードを実行される危険性があります。「VMware vCenter」のディレクトリサービスにおける認証回避（CVE-2026-123903）も含め、これら3件はCVSSv3.1基本値で「9.8」と極めて高いスコアが付与されています。さらにESX、Workstation、Fusion共通のUSBコントローラにおける域外書き込み（CVE-2026-123912）なども確認されています。

[出典: Security NEXT - 「ESX」「vCenter」などVMware製品に23件の脆弱性](https://www.security-next.com/193422)

### 2. 「Drupal」が再アップデート、前回更新後も一部サイトは脆弱 - 侵害調査を

Drupalセキュリティチームは2026年11月25日、セキュリティアドバイザリ（SA-CORE-2026-019）を公開し、アクセス制限を回避できる脆弱性「CVE-2026-136716」を明らかにしました。1週間前の11月18日にインストーラ関連の脆弱性（CVE-2026-132165）の修正版が提供されていましたが、その対応が不十分であったことが判明しました。
インストールの未完了など通常と異なる状態にあるサイトでは、前回の更新を適用済みであっても認証なしで遠隔からサイトを乗っ取られる危険性が残存しています。脆弱性の重要度は5段階中最高レベルの「高クリティカル（Highly critical）」とされており、すでに悪用が確認されているため、利用者はアップデートの適用とともに侵害の有無について調査することが強く推奨されています。なお、推奨されているインストーラ保護策を実施しているサイトは影響を受けません。

[出典: Security NEXT - 「Drupal」が再アップデート、前回更新後も一部サイトは脆弱 - 侵害調査を](https://www.security-next.com/193451)

### 3. 「SolarWinds Serv-U」に脆弱性 - 9件が「クリティカル」

SolarWindsは現地時間2026年11月24日、ファイル転送ソリューション「SolarWinds Serv-U」の最新版「Serv-U 2026.4」をリリースしました。自社製品固有の脆弱性18件が修正され、そのうち9件が4段階中最高位の「クリティカル（Critical）」と判定されています。
Linux環境においてroot権限への昇格を許す脆弱性（CVE-2026-123172、CVE-2026-123168）や、型の取り違えによりドメイン管理者がシステム管理者権限を奪取できる問題（CVE-2026-82320、CVE-2026-82321）が含まれます。また、アクセス権確認から実際のアクセスまでの時間差を突く競合状態の脆弱性（CVE-2026-82315、CVE-2026-82316、CVE-2026-82319）により、非認可ファイルの改ざん・読み込みやコード実行、権限昇格に至るおそれがあります。

[出典: Security NEXT - 「SolarWinds Serv-U」に脆弱性 - 9件が「クリティカル」](https://www.security-next.com/193429)

## 深掘り

### 管理機能・インフラ運用ツールを標的とした認証回避と権限昇格

仮想化基盤、ファイル転送ゲートウェイ、ネットワーク管理ソフトウェアなど、システム中枢を担うソフトウェアにおいて、認証のバイパスや特権奪取につながる脆弱性が集中して表面化しています。

#### 認証バイパスと遠隔コード実行の脅威

VMware vCenterのディレクトリサービス（CVE-2026-123903）やHPE AirWaveの管理インタフェース（CVE-2026-133971、CVE-2026-133972）では、外部の第三者が認証なしで管理者権限やAPI操作権限を取得できる問題が確認されました。これらはCVSSv3.1で「9.8」と評価されており、認証境界が破られることで即座にOSコマンド実行やシステム完全掌握へと連鎖する構造的脅威を抱えています。

#### 競合状態（TOCTOU）とメモリ管理不備による特権奪取

SolarWinds Serv-Uで確認された競合状態の不具合（CVE-2026-82315等）は、権限検証時とファイル操作実行時のタイムラグを突くことで制限を回避します。また、VMware ESXのI/OフィルタサービスにおけるUse-After-Free（CVE-2026-123911）や域外書き込みなど、基盤レイヤでのメモリ破壊脆弱性は、ハイパーバイザやホストOSの実行権限を奪う重大な要因となります。

### 関連知識

今回のインシデントおよびセキュリティアップデートから読み解くべき背景技術と運用上の課題です。

#### 用語解説

* **パストラバーサル（Path Traversal）**: BusyBoxのtftpd（CVE-2026-136411）などで確認された脆弱性。入力されたファイルパスの検証不備を突き、相対パス「../」や想定外の絶対パスを用いて本来アクセスが制限されている上位ディレクトリのファイルを不正に読み書きする手法です。
* **CVSSv3.1 / CVSSv4.0**: 情報システムの脆弱性の深刻度を評価する国際基準。ネットワーク経由で攻撃可能、攻撃複雑度が低く、特権やユーザ関与が不要なリモートコード実行や認証回避は、CVSSv3.1において「9.8」などの極めて深刻なスコアとなります。
* **型の取り違え（Type Confusion）**: オブジェクトのデータ型が正しく処理されず、不正なメモリアクセスや特権昇格（Serv-Uにおけるドメイン管理者からシステム管理者への昇格など）を引き起こす脆弱性です。

#### 今後の展望

Drupalの事例が示すように、一度パッチが公開されても特殊な環境下やエッジケースにおいて対策が不完全となるリスクがあります。単にパッチを機械的に適用するだけでなく、ベンダーのアドバイザリに記載された前提条件や推奨設定（Drupalにおけるインストーラ保護策など）が実環境に正しく反映されているかを再点検し、侵害の痕跡（IoC）がないか継続的にログを監査する体制が必要です。

## 結論

今回のセキュリティ動向では、VMware、SolarWinds、HPE、Drupal、BusyBoxなど、企業の基幹業務やITインフラを支える主要ソリューションにおいてCVSS 9点台を超える極めて重大な脆弱性が集中しました。特にDrupalのようにパッチ適用後も条件次第で乗っ取りが可能となり、既に悪用事例が発生しているケースもあるため、セキュリティ担当者は最新アドバイザリの追跡、迅速なアップデート適用、そして不完全なインストール環境の棚卸しと侵害調査を即座に実施することが求められます。
