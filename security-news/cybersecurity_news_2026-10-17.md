#  2026年10月17日  サイバーセキュリティニュースまとめ

## 主要ポイント
*  Web制作プラットフォーム「Studio」のクラウド環境不正アクセスにより、LUUP（約2.1万件）やラクスル（6,412件）、自治体など利用企業の問い合わせフォーム情報やAPIキーが連鎖流出。
*  Eストアー「ショップサーブ」の最終報告にて約2,335.6万人分の個人情報漏洩が確定したほか、ソースネクスト（最大2,252万件）やバーガーキング（1,118万件）など超大規模なデータ侵害が同時公表。
*  ConnectWiseのクラウドバックアップ基盤侵害を通じたM365非人間アイデンティティ（NHI）乗っ取りや、リアルタイム入札（RTB）網を悪用したゼロクリックスパイウェア「AdFection」などグローバルなサプライチェーン攻撃が拡大。

##  SaaS・クラウド共通基盤の侵害とサプライチェーン連鎖被害
ノーコードWeb制作プラットフォーム「Studio」のクラウド環境において、機能上の脆弱性を突いた第三者による不正アクセスが発生しました。暗号化データの復号に必要な鍵も共に読み出されたため、Studio本体の顧客アカウント情報にとどまらず、同サービスを利用してWebサイトを構築していたLUUP（21,368件）、Link-Uグループ（7,663件）、ラクスル（6,412件）、フラー（6,029件）、Fukuoka Growth Next（629件）、さいたま緑の森博物館（162件）などの問い合わせフォーム送信内容や外部APIキーが連鎖的に流出・露出可能状態となりました。

##  EC・プラットフォームにおける数千万人規模の大量個人情報漏洩
国内の電子商取引および大手サービスプラットフォームにおいて、過去最大級となる大量データ強奪被害の全貌が判明しました。Eストアーは「ショップサーブ」への不正アクセスに関する最終報告を発表し、7,858店舗・計約2,335万6,000人分の顧客情報（うち約209万6,900人はカード番号の一部等含む）の流出を確定しました。さらにソースネクストでの会員情報取得APIの不正利用による最大2,251万9,960件の流出、バーガーキング公式アプリでの約1,118万件の漏洩など、プラットフォームを標的とした大規模なデータ侵害が相次ぎました。

##  非人間アイデンティティ（NHI）悪用とゼロクリック・スパイウェアなどの国際的脅威
海外においては、IT管理ソフトウェア大手ConnectWiseのクラウドバックアップサービス（旧SkyKick）がサプライチェーン攻撃を受け、162以上のMicrosoft 365テナントへ不正侵入されました。攻撃者はユーザーアカウントではなく認証情報（Entra ID Service Principal）を悪用することで多要素認証（MFA）を完全に回避し、最高管理者権限（Global Admin）を獲得して組織内のメールやドキュメントを強奪しました。また、リアルタイム広告入札（RTB）網を悪用してゼロクリックでCandiruスパイウェアを注入する「AdFection」キャンペーンや、Drupalコアにおける未認証RCE脆弱性（CVE-2026-108097等）など、基盤層を狙う攻撃が高度化しています。

## ニュース紹介

### 1.  Web制作SaaS「Studio」の不正アクセスと利用企業・自治体への広域連鎖影響
ノーコードWeb制作プラットフォームを運営するStudio株式会社は、同社が利用するクラウド環境に対し一部機能の脆弱性を悪用した不当なアクセスが発生したと発表しました。
*   **発生した事象と影響**：攻撃者はクラウド環境内の全読み取り権限を獲得し、全登録顧客のアカウント情報（メールアドレス、ハッシュ化パスワード等）に加え、デザインデータ、問い合わせフォームの送信内容、Webhook通知先URL、外部連携用のAPIキーやトークンを外部から取得可能な状態にしていました。特にフォーム送信内容やAPIキー等は暗号化して保存されていたものの、同一環境内に配置されていた復号鍵も共に読み出されたため、平文での解読リスクが生じています。これを受け、LUUP（21,368件）、Link-Uグループ（7,663件）、ラクスル（6,412件）、フラー（6,029件）などの利用企業や自治体が相次いでフォーム送信データの漏洩可能性を公表する二次被害へ発展しました。
$$出典: Studio.Design - 【重要】不正アクセスによる情報流出に関するお詫びとお願い（第一報）$$ (https://studio.design/ja/whats-new/unauthorized-access-2026-10)

### 2.  Eストアー「ショップサーブ」不正アクセス最終報、約2,335万件の漏洩が確定
ECサイト構築・運営支援サービス「ショップサーブ」を手掛ける株式会社Eストアーは、サーバー上のアプリケーション脆弱性を突かれた不正アクセス事案について最終フォレンジック調査結果を公表しました。
*   **発生した事象と影響**：2026年5月21日から8月1日にかけてデータベース内の情報が外部へ継続送信されており、対象店舗7,858店、利用客約2,335万6,000人分の個人情報（氏名、住所、電話番号、メールアドレス等）の漏洩が確定しました。このうち約209万6,900人分については、クレジットカード名義、有効期限、およびカード番号の一部（先頭6桁・下4桁）が含まれていたことが判明しました。完全なカード番号やセキュリティコード（CVV）は保持していなかったため、当該データのみでの不正決済は不可能な構造となっています。
$$出典: ITmedia ビジネスオンライン - ECサイト運営支援「ショップサーブ」で約2335万人の情報漏えい クレカ情報も一部流出（1/2 ページ）$$ (https://www.itmedia.co.jp/business/articles/2610/17/news019.html)

### 3.  ConnectWiseクラウドバックアップ侵害を通じたM365非人間アイデンティティ（NHI）強奪攻撃
IT管理ソフトウェアベンダーのConnectWise社は、同社の「Cloud Backup」（旧SkyKick）インフラがサプライチェーン攻撃を受け、グローバルアクセスを緊急遮断したことを公表しました。
*   **発生した事象と影響**：攻撃者はConnectWiseの管理インフラ内で使用されていたアプリケーション識別子（Entra ID Service Principal）のシークレットを窃取しました。これにより、162以上のMicrosoft 365顧客テナントに対し、ユーザーログインを経由しないサービス間直接通信（Non-Interactive Authentication）を用いて侵入を達成しました。MFAによる検証を完全に回避した上で「Directory.ReadWrite.All」等の特権が付与され、わずか5分以内に別管理アプリへ二次シークレットを登録して永続的バックドアを構築。Exchangeメール、SharePoint、OneDrive、Teamsの全データが外部へ持ち出されました。
$$出典: BleepingComputer - Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack$$ (https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/)

## 深掘り

###  SaaS基盤・非人間アイデンティティ（NHI）の構造的脆弱性とKYCデータ保持リスク

####  1. 暗号鍵同居・API認証情報強奪によるサプライチェーン連鎖のメカニズム
StudioやConnectWiseの事案で顕著となったのは、マルチテナントSaaS基盤単一の脆弱性が、その下流に位置する無数の企業・自治体・顧客環境へ一瞬で波及する連鎖構造です。
Studioの事例では、データベース上のフィールド（フォーム回答やAPIキー）が暗号化されていたものの、復号に使用する秘密鍵や環境設定ファイルが同一のクラウドプロジェクトストレージ内に置かれていたため、ストレージの読み取り権限を獲得した攻撃者によって暗号化が無効化されました。さらに、SaaS基盤に登録されていた外部サービス連携用のAPIキーやスプレッドシート認証トークンが流出したことで、利用企業側はトークンの即時無効化と再発行、監査ログの緊急精査という大規模な一次対応を余儀なくされました。

####  2. 運転免許証画像など高信頼性本人確認（KYC）データ流出に伴うなりすましリスク
タイムズカー（約660万件流出・免許証画像約160万件含む）や各種サービスの侵害事故において、最も重大な二次被害をもたらすのが高精細な運転免許証や身分証明書画像データの漏洩です。
元警察庁サイバー警察局長の分析によると、暗号化パスワードやクレジットカード番号（変更・利用停止が可能）とは異なり、氏名・生年月日・住所・本人の顔写真・免許証番号といった政府発行の身分証明データは変更不可能です。攻撃者は盗み出した免許証画像やディープフェイク動画生成技術を組み合わせてオンライン本人確認（eKYC）を突破し、偽造口座の開設、不正なクレジットカード・携帯電話契約、ならびに役員等を標的とした精巧なスピアフィッシング攻撃へ即座に悪用（ウェポナイゼーション）します。

###  関連知識

####  用語解説
*   **非人間アイデンティティ（Non-Human Identities / NHI）**：サービスプリンシパル、OAuthアプリケーション、APIキー、サービスアカウントなど、人間ではなくプログラムやシステム同士が認証・通信を行うために用いる識別情報。MFAが適用されないため、シークレット漏洩時に広範な管理者権限を即座に奪取される危険性があります。
*   **BFLA（Broken Function Level Authorization / 機能レベル認可の欠落）**：OWASP API Security Top 10の主要脆弱性。サーバー側で呼び出し元の役割や権限に応じた機能実行可否の検証を行っていないため、一般ユーザーや外部攻撃者が管理者用・内部用APIエンドポイントを直接実行してデータを一括抽出できてしまう欠陥。
*   **データミニマイゼーション（Data Minimization / データの最小化）**：事業運営に必要な最小限の個人情報のみを収集・保持し、利用目的を終えた問い合わせログや過去の本人確認画像をデータベースから即座に自動消去・物理分離・非保持化するセキュリティ設計原則。

####  今後の展望
*   **ハードウェアセキュリティモジュール（HSM）による鍵分離の義務化**：
    暗号化データと復号鍵の同一バケット配置を防ぐため、専用の鍵管理サービス（KMS）やKMS/HSMを用いたキーライフサイクルの厳格な分離がSaaS事業者の標準要件となります。
*   **eKYCにおけるICチップ直接読み取りへの完全移行**：
    画像データ送信方式によるオンライン本人確認の限界が露呈したため、偽造が困難なマイナンバーカードや運転免許証の物理ICチップ読み取り（FIDO2/WebAuthnやPKI直接検証）への前倒し移行が金融機関および事業者間で急速に推進されます。

## 結論
2026年10月中旬に集中発生したインシデント群は、共通SaaSプラットフォームやAPI連携機能の不備が、一瞬で無数の利用企業や自治体へ被害を連鎖させる現代サイバー空間の構造的リスクを証明しました。
企業の経営層およびCISOは、従来の「自社ネットワークの境界防衛」のみに頼るアプローチを捨て、外部SaaSおよび非人間アイデンティティ（NHI）の認可統制、不要な過去データや本人確認画像の即時完全消去（データミニマイゼーション）、並びに「侵害前提（Assume Breach）」に基づくゼロトラストアーキテクチャの確立を速やかに断行すべきです。
