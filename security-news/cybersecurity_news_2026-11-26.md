# 2026年11月26日 サイバーセキュリティニュース詳細

## ニュース紹介

### 1. 悪用確認済みの脆弱性10件を「KEV」に追加 - 米当局

米サイバーセキュリティインフラストラクチャセキュリティ庁（CISA）は、現地時間2026年11月25日に「悪用が確認された脆弱性カタログ（KEV）」へ新たに10件の脆弱性を追加しました。対象には、Mitelの音声・ビデオ会議ツール「MiCollab」に存在するOSコマンドインジェクション（CVE-2026-133323）やXMLインジェクション（CVE-2026-133303）、ファイルアップロード不備（CVE-2026-133275）など5件が含まれます。これらを悪用されると、未認証の状態で任意のコマンド実行や不正操作、機密情報の窃取が行われる危険性があります。さらに、Juniper Networksの「Session Smart Conductor」「Session Smart Router」においてリモートよりroot権限で任意のコマンドを実行される脆弱性（CVE-2026-103406）や、仮想化管理ツール「Xen Orchestra」の認証回避脆弱性（CVE-2026-133469）も悪用対象として登録されました。

[出典: Security NEXT - 悪用確認済みの脆弱性10件を「KEV」に追加 - 米当局](https://www.security-next.com/193360)

### 2. DellのネットワークOSに深刻な脆弱性 - 800件弱の脆弱性に対応

Dellは、ネットワークOS「Dell Enterprise SONiC Distribution」に関するセキュリティアドバイザリ（DSA-2026-451）を公開し、重要度をもっとも高い「クリティカル（Critical）」と評価しました。今回のアップデートでは、製品固有の脆弱性13件に加え、依存関係にあるサードパーティ製ソフトウェアに関する778件、合わせて約800件の脆弱性が修正されています。製品固有の脆弱性のうち、「CVE-2026-103782」（CVSSv3.1基本値 9.9）は引数インジェクションの不備に起因し、低権限ユーザによるリモートコマンド実行やファイルシステムリソースへの不正アクセスを招く恐れがあります。また、隣接ネットワークから未認証で任意コマンドを実行可能なOSコマンドインジェクションの脆弱性「CVE-2026-103788」（CVSSv3.1基本値 9.6）なども解消されています。

[出典: Security NEXT - DellのネットワークOSに深刻な脆弱性 - 800件弱の脆弱性に対応](https://www.security-next.com/193319)

### 3. 「Joomla」に58件の脆弱性 - 「クリティカル」は4件

コンテンツ管理システム（CMS）である「Joomla」の開発チームは、セキュリティアップデートとなる「Joomla 6.2.1」および「Joomla 5.4.11」を公開しました。本アップデートではCVEベースで58件の修正が実施され、そのうち4件がCVSSv3.1ベーススコアで最上位の「クリティカル（Critical）」にレーティングされています。具体例として、運用環境にインストールディレクトリが残存している場合に認証なしで設定書き換えが可能な「CVE-2026-123214」や、メディア向けカスタムフィールド処理におけるXML生成のエスケープ不備によってリモートコード実行が引き起こされる「CVE-2026-129393」、ログ出力処理の競合状態により保護ヘッダなしでファイルが再生成されリモートコード実行に至る「CVE-2026-127297」などが報告されています。

[出典: Security NEXT - 「Joomla」に58件の脆弱性 - 「クリティカル」は4件](https://www.security-next.com/193353)

## 深掘り

### ネットワーク機器およびサプライチェーンの脆弱性リスク

今日のエンタープライズインフラにおいて、ネットワーク製品やAI基盤、CI/CDツールを標的とした攻撃が常態化しています。特に境界防御を担うネットワークアプライアンスや、運用基盤となるソフトウェアコンポーネントの欠陥は、一度侵入を許すと広範なインフラ全体の制御権を奪われる危険性を孕んでいます。

#### サードパーティ製コンポーネント依存の拡大

Dell Enterprise SONiC Distributionの事例では、製品自体の脆弱性13件に対してサードパーティ製コンポーネントに起因する脆弱性が778件と、全体の大部分を占めています。オープンソースソフトウェアや共通ライブラリを組み込んで構築される現代のネットワークOSでは、基盤となるディストリビューションやライブラリ群のセキュリティパッチ追従が製品全体の堅牢性を大きく左右します。

#### 認証回避と遠隔コマンド実行の連鎖

Mitel製品やJoomla、Jenkins、NVIDIA AIStoreで報告された脆弱性に共通するのは、「未認証での侵入」および「リモートコード実行（RCE）」の危険性です。外部に公開された管理インタフェースや機能に認証回避・インジェクションの不備が存在する場合、攻撃者は特権を持たずに侵入し、インフラ内部への足がかりを容易に構築することが可能となります。

### 関連知識

今回のニュースを理解・評価する上で重要となる背景情報およびセキュリティ評価指標について整理します。

#### 用語解説

* **KEV（Known Exploited Vulnerabilities Catalog）**: 米CISAが管理・公開している「悪用が確認された脆弱性カタログ」。実際にサイバー攻撃で武器化・悪用されている脆弱性が登録され、米連邦政府機関に対して適用期限付きの修正命令が出されるほか、世界中の民間組織でも対応優先度を判断する基準として活用されている。
* **CVSSv3.1（Common Vulnerability Scoring System v3.1）**: 脆弱性の深刻度を同一の基準で比較・評価するためのオープンな指標。攻撃元区分、攻撃条件の複雑さ、必要な特権、影響範囲などを加味して0.0から10.0のスコア（基本値）を算出し、「低」「中」「高」「クリティカル」の重要度に分類する。
* **引数インジェクション（Argument Injection）**: プログラムが外部コマンドを呼び出す際、入力文字列の検証やエスケープが不十分なために不正なコマンドラインオプションや引数が挿入・解釈され、意図しない処理やコマンド実行が行われてしまう脆弱性。

#### 今後の展望

CISAのKEVカタログ追加が示す通り、既知の脆弱性公開から実際の悪用開始までのタイムラグは著しく短縮されています。また、Jenkinsの「CVE-2026-136835」のように、開発チーム評価（CVSS 7.5）とCISA評価（CVSS 9.9）で重要度の見解が分かれるケースも生じています。管理者は単一のベンダー評価のみに頼るのではなく、KEVカタログなどの脅威インテリジェンスや自組織の露出状況・ネットワーク構成を照らし合わせ、優先順位をつけて迅速にパッチ適用や設定見直しを進める動的な脆弱性管理体制が求められます。

## 結論

2026年11月26日発表のセキュリティ動向では、ネットワークOS、Web基盤、AIストレージ、CI/CD環境に至るまで、多層的なインフラ基盤を標的とする深刻な脆弱性の報告が相次ぎました。特に、実際に悪用が確認された製品に対するパッチ適用と、膨大なサードパーティ製コンポーネントを内包するソフトウェアサプライチェーンの継続的な脆弱性監視・アップデートが急務です。
