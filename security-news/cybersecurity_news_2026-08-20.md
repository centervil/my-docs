# 2026年8月20日 サイバーセキュリティニュースまとめ

## 主要ポイント
* **さくらインターネットで最大136万アカウントへの不正アクセス影響が判明**：「さくらのレンタルサーバ」の侵害調査の過程で、別の「販売管理システム」への不正アクセスが新たに確認され、最大1,360,563会員のアカウント情報および一部のハッシュ化パスワードが閲覧・取得された可能性が公表されました。
* **大阪・関西万博の再委託先における不正アクセスと情報漏洩のおそれ**：従業員のフィッシングメール受信に起因して再委託先のMicrosoft 365アカウントが侵害され、万博のイベント出演者のスピーチ原稿や進行台本、関係者の個人情報などが漏洩したおそれがあります。
* **Microsoft Entra IDの最高深刻度（CVSS 10.0）脆弱性が野生で悪用される**：デシリアライゼーションの不備による遠隔コード実行脆弱性（CVE-2026-69836）が実際の攻撃で悪用され、Microsoftがクラウドサービス側で自動的な緩和を完了しました。

## 国内インフラおよびサプライチェーンへの不正アクセス
国内のサービス事業者や大規模イベントの委託先環境における不正アクセスが目立っています。さくらインターネットの契約情報を管理するシステムや、大阪・関西万博の催事業務を担う再委託先のクラウドアカウント、さらにはエヌ・イー ケムキャットの従業員アカウントなどが、フィッシングメールやマルウェアを契機として不正利用され、隔離されていたはずの機密データや個人情報に影響が及ぶ事態が発生しています。

## クラウドプラットフォームと基盤ツールの最高深刻度脆弱性
クラウド管理やデータ分析などに広く利用される共通基盤ツールで、極めて深刻な脆弱性が相次いで確認されています。Microsoft Entra IDのリモートコード実行脆弱性（CVSS 10.0）や、機械学習プラットフォーム「MLflow」のSSRF脆弱性（CVE-2026-64849）、オープンソースBIツール「Metabase」のSQLインジェクション脆弱性（CVE-2026-72898）が、いずれも野生（現実の攻撃）で悪用されたとして、米CISAなどの当局による警告やカタログへの登録が行われています。

## 個人標的型の詐欺急増とセキュリティ被害の長期化
個人や企業従業員を直接狙う詐欺手口の高度化と、それに伴う企業のインシデント被害の拡大が明らかになっています。テクニカルサポート詐欺が急増しているほか、著名人を騙るSNS投資詐欺は分業体制で組織化され、ニセ警察詐欺にはビデオ通話でのディープフェイク偽装が確認されました。また、企業のランサムウェア被害額は平均約3億4,800万円、復旧までの業務停止時間は約36.0日に長期化しています。

# 2026年8月20日 サイバーセキュリティニュース詳細

## ニュース紹介

### 1. さくらインターネットの「販売管理システム」への不正アクセスによる最大136万アカウントの影響懸念
さくらインターネットは、「さくらのレンタルサーバ」の583アカウントに対する不正ログイン被害（第一報）の調査を継続した結果、新たに顧客の契約情報などを管理する「販売管理システム」への不正アクセスの可能性を確認したと公表しました。閲覧・取得された可能性のある情報は、最大1,360,563アカウントの会員ID、氏名、住所、電話番号、メールアドレス等、および一部（30アカウント）のハッシュ化パスワード情報です。なお、クレジットカード情報は自社で保持していないため影響はありません。
* 出典: さくらインターネット - 当社システムへの不正アクセスに関するお知らせ（第二報）（https://www.sakura.ad.jp/corporate/information/newsreleases/2026/08/19/1968225633/）

### 2. 大阪・関西万博の再委託先における不正アクセスとイベント出演者等の情報漏洩懸念
2025年日本国際博覧会協会は、催事業務などを委託している企業の「再委託先」において、Microsoft 365アカウントに対する不正アクセスが発生したと発表しました。2026年5月13日、再委託先の従業員が海外企業を装うフィッシングメールを受信したことが端緒です。漏洩のおそれがあるのは、関係者の連絡先や勤務シフト、およびイベント出演者の写真、スピーチ原稿、進行台本、ステージの登壇・退場動線などです。一般来場者の情報やクレジットカード情報、および二次被害は現時点で確認されていません。
* 出典: 公益社団法人2025年日本国際博覧会協会 - 発表情報（https://www.expo2025.or.jp/news/news-20260820-01/） / ITmedia NEWS - 大阪万博の関係者情報が漏えいか 再委託先のMicrosoft 365アカウントに不正アクセス（https://www.itmedia.co.jp/news/article/2608/20/2000000657/）

### 3. Microsoft Entra IDにおける最高深刻度10.0の遠隔コード実行脆弱性（CVE-2026-69836）の野生での悪用
Microsoftは、クラウドベースのID管理サービス「Entra ID」（旧Azure AD）において、信頼されていないデータのデシリアライゼーション不備に起因するリモートコード実行（RCE）の脆弱性（CVE-2026-69836、ベーススコア10.0）が実際に野生で悪用されたと警告しました。認証されていない攻撃者がネットワーク経由で不正データを送信し、システム上で任意のコードを実行させるおそれがあります。本脆弱性はMicrosoft側で完全に自動緩和（パッチ適用）が適用されており、ユーザー側の追加対応は不要とされています。
* 出典: The Hacker News - Microsoft Entra ID Flaw (CVSS 10.0) Exploited in Wild, Allows Remote Code Execution (https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html)

## 深掘り

### サプライチェーン及び周辺管理システムを狙うサイバー攻撃の構造
近年、組織自体のコアインフラを直接突破するのではなく、比較的統制の弱い「再委託先」や、論理的に接続された「周辺の管理システム」を最初の足がかり（初期侵入）として利用し、そこから機密データへ到達する迂回型のサイバー攻撃が増加しています。

#### フィッシングを契機としたクラウドアカウントの侵害とデータ露出の連鎖
大阪・関西万博の事例では、再委託先における従業員のフィッシングメール受信という極めて一般的な事象から、Microsoft 365アカウントへの不正アクセスが成立しました。業務効率化のためにクラウド上で共有されていたメールや見積書、進行台本、出演者のスピーチ原稿などの広範囲な機密情報が、単一のアカウント（認証情報）侵害を介して、一網打尽に第三者から閲覧・取得可能なおそれ（単一障害点）に晒されるという、クラウド運用上の構造的なリスクを示しています。

#### 管理システム・周辺環境という「隔離された信頼境界」への迂回侵入
さくらインターネットの事例では、直接のレンタルサーバー環境のみならず、顧客の会員IDやパスワードを含む「販売管理システム」への不正アクセスが新たに確認されました。また、エヌ・イー ケムキャットでも、第三者が従業員アカウントを不正に利用して端末上でマルウェアを実行し、社内システムから個人情報が漏えいしたおそれが発生しています。サービス提供環境自体が堅牢であっても、それらを管理するための運用システムや周辺環境、従業員アカウントといった「見えない境界」が突破されることで、内部から論理的なデータ分離をバイパスされる危険性が浮き彫りとなっています。

### 関連知識

#### 用語解説
* **信頼されていないデータのデシリアライゼーション（Deserialization of untrusted data）**：
  シリアル化されたデータ（転送や保存のために変換されたデータ構造）を復元する際、その検証を適切に行わないために、攻撃者から送られた不正な命令やコードをシステム上でそのまま実行してしまう脆弱性。Entra ID（CVE-2026-69836）の根本原因です。
* **SSRF（Server-Side Request Forgery）**：
  攻撃者が脆弱なWebアプリケーション（今回は機械学習プラットフォーム「MLflow」のWebhook配信機能）を介して、通常は外部から直接アクセスできない内部ネットワークのサービスやクラウド環境のメタデータサービスに不審なリクエストを送信させ、認証情報などを窃取する手法。
* **ハッシュ化パスワード（Hashed Password）**：
  元のパスワードに復元することが困難な状態に、ハッシュ関数を用いて不可逆変換したパスワードデータ。さくらインターネットでは30アカウントに影響の可能性が確認されています。

#### 今後の展望
* **契約ガバナンスを重視した委託先・再委託先（サプライチェーン）管理の徹底**：
  個人情報保護法の義務により、不正アクセスに伴う個人情報漏洩（またはそのおそれ）が発生した際、企業は3〜5日以内という極めてタイトな期限での個人情報保護委員会への「速報」対応が求められます。荷主や委託元がこの速報体制を維持するためには、委託先（および再委託先）の段階でインシデントを速やかに報告し、保有期間を過ぎた個人情報を確実に「廃棄・消去」させる仕組みを、あらかじめ「業務委託契約書」の通知条項・監査条項として具体的に明文化しておくことが不可欠となります。
* **物理的なバインディング技術と不要な「検証環境」の排除**：
  フィッシングによるクラウドアカウントのセッション窃取を防ぐため、多要素認証（MFA）をさらに強化し、認証セッションをアクセス元デバイスの物理セキュリティチップ（TPM等）に直接紐づけるバインディング技術の導入が推奨されます。また、「検証用のまま」十分なアクセス制限をかけずにインターネットに公開され放置されているBIツール（Metabase等）や機械学習プラットフォーム（MLflow等）がないか、自社のシャドーIT環境を棚卸しする習慣が極めて重要となります。

## 結論
直近で公表されたセキュリティインシデントは、攻撃者が企業の「堅牢な直接防壁」を避け、クラウドアカウントの認証情報、再委託先の不備、あるいは管理ツールといった「信頼された境界の内側や裏口」を突くアプローチへと極めて高い効率性で移行していることを示しています。もはやセキュリティ対策は、一企業の「売上を直接生まないコスト削減対象」ではなく、サプライチェーン全体を安全に維持し、社会的信用や業務停止に伴う多大な賠償リスクを回避するための「インフラ維持費」としてパラダイムシフトさせる必要があります。組織は、自社のみならず委託先までを含めた多層的な「ガバナンスと集団防衛（流通ISAC等への参加含む）」にリソースを投資すべき時期に来ています。
