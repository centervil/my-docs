## 主要ポイント
*  **画像共有サービス「Gyazo」における大規模不正アクセス**：画像アップロードサーバーの脆弱性を突かれ、ユーザー情報約2,362万件および画像メタデータ約4.9億件が流出しました。
*  **Cisco ISEにおける最高深刻度ゼロデイ脆弱性（CVE-2026-76460）のアクティブ悪用**：認証不備により未認証のリモートからroot権限を奪取されるCVSS 10.0の脆弱性が悪用され、CISAもKEVカタログに追加しました。
*  **国内Webサービスや通信事業者での個人情報事故が相次ぐ**：ムラウチドットコムでの不正アクセス（771万件流出）やさくらインターネットでの平文初期パスワード露出、@cosmeの設定ミス、ドコモの同意なきデータ提供などが同時期に公表されました。

##  画像共有サービスおよびWebインフラにおける大規模データ侵害
株式会社Helpfeelが運営する「Gyazo」において、画像アップロードサーバーの脆弱性を起点とした不正アクセスが発生し、ユーザー情報約2,362万件と画像のメタデータ約4.9億件が流出しました。流出情報にはメールアドレス、パスワードのハッシュ値、セッションID、外部SSOトークンが含まれます。また、URL構造を含むメタデータが露出したことで非公開画像が閲覧可能となったおそれがあり、同社は一部画像の閲覧を一時無効化する措置を講じました。

##  ネットワーク境界アプライアンス・管理基盤における重大脆弱性とゼロデイ悪用
Cisco Systemsは、Identity Services Engine（ISE）およびISE Passive Identity Connector（ISE-PIC）の管理用REST APIにおける認証制御の不備（CVE-2026-76460、CVSS 10.0）がゼロデイとして悪用されていると発表しました。未認証のアタッカーが細工したHTTPリクエストにより管理画面を回避し、root権限で任意コマンドを実行できる状態となっていました。さらに、WSO2 API Manager（CVE-2026-5430）やConnectWise ScreenConnect（CVE-2026-84869）、Acronisバックアッププラグイン（CVE-2026-87886）など、管理・開発基盤に対する野生悪用が激化しています。

##  国内Webサービス・通信事業者における個人情報漏洩・管理不備事案
国内では、原因や被害形態の異なる複数の個人情報事故が相次いで発表されました。ムラウチドットコムではWebシステムの脆弱性を起点に複数のシステムへ侵入され、771万6,811件の顧客情報が外部へ持ち出されたことが確定しました。さくらインターネットでは販売管理システム等の不正アクセス調査により最大136万件の会員情報閲覧可能性と、一部レンタルサーバー・VPS初期パスワードの平文保存が判明しました。@cosmeではファイル転送サービスの設定ミスによる一時的な閲覧可能状態、NTTドコモでは同意画面の記述欠落によるAmazonへの約34万回線分の情報無断提供が発生しました。

#  2026年9月17日  サイバーセキュリティニュース詳細

## ニュース紹介

### 1.  画像共有サービス「Gyazo」における不正アクセスと大規模メタデータ・ユーザー情報流出
株式会社Helpfeelは2026年9月16日、画像共有サービス「Gyazo」の画像アップロードサーバーに存在する脆弱性を悪用され、システム上で任意コマンドを実行される不正アクセスが発生したと公表しました。
*   **事象と影響範囲**：調査の結果、ユーザー情報約2,362万件（名前、メールアドレス、パスワードのハッシュ値、ログインセッションID、X用連携トークン、Google SSOメールアドレス等）が流出したことが確認されました。クレジットカード等の決済情報は含まれていません。
*   **メタデータ露出と非公開画像への影響**：画像IDやURL構成要素、位置情報（EXIF）、OCRテキストを含む画像メタデータ約4.9億件が取得されました。Gyazoでは予測困難なURLによって非公開画像の制限を行っていたため、メタデータの露出により非公開画像が第三者に閲覧された可能性が否定できず、一部画像の配信停止・一時無効化やセッションキーの無効化が実施されました。
\\[出典: 窓の杜 - 画像共有サービス「Gyazo」に不正アクセス、非公開画像が閲覧された可能性も\\] (https://forest.watch.impress.co.jp/docs/news/2141601.html)

### 2.  Cisco Identity Services Engine（ISE）における最高深刻度ゼロデイ脆弱性（CVE-2026-76460）のアクティブな悪用
Cisco Systemsは、認証・認可統合管理ソリューション「Cisco Identity Services Engine (ISE)」および「ISE Passive Identity Connector (ISE-PIC)」に存在する最高深刻度（CVSSスコア 10.0）の脆弱性「CVE-2026-76460」が、実際の攻撃で悪用されているとして緊急アドバイザリを公表しました。
*   **技術的詳細と攻撃の影響**：行政・管理用REST APIエンドポイントにおける認証制御の欠落に起因し、リモートの未認証攻撃者が細工したHTTPリクエストを送信することでWeb管理インターフェースを迂回し、システム上で直接root権限コマンドを実行可能です。
*   **証跡消去と対応策**：root権限を獲得された場合、攻撃者は`access.log`などの実行ログや侵入形跡（IoC）を消去・改ざんできるため、Ciscoはマルチノードでのログ突合や再イメージング（初期化復元）を推奨しています。米CISAは本件をKEV（悪用が確認された脆弱性）カタログに追加し、連邦機関へ3日以内のパッチ適用を指示しました。
\\[出典: SecurityWeek - Active Exploitation Triggers Emergency Patch for Cisco ISE Zero-Day\\] (https://www.securityweek.com/active-exploitation-triggers-emergency-patch-for-cisco-ise-zero-day/)

### 3.  ムラウチドットコム、さくらインターネット、@cosme等における個人情報事故の相次ぐ公表
2026年9月15日から16日にかけて、国内の複数事業者から個人情報に関連するセキュリティインシデントおよび設定ミスが相次いで公表されました。
*   **ムラウチドットコム（不正アクセス・持ち出し確認）**：Webシステムの脆弱性を起点に内部ネットワークへ侵入され、顧客の氏名、住所、電話番号、メールアドレス、生年月日等、計771万6,811件の個人情報が外部へ持ち出されたことが確定しました。パスワードや決済情報は別システム管理のため流出対象外です。
*   **さくらインターネット（長期侵入と平文初期パスワード）**：販売管理システム等への不正アクセス最終調査結果で、会員・契約情報136万0,563アカウントの閲覧・取得可能性と、レンタルサーバー・VPSの一部初期パスワードがシステム内に平文保存されていた運用欠陥が報告されました。同社は「さくらのレンタルサーバ」全サーバーの再構築や初期パスワードの変更措置を進めています。
*   **@cosmeおよびドコモ（設定ミスおよび同意不備）**：@cosmeでは外部ファイル転送サービスの設定ミスにより約20分間10,997人分の情報が閲覧可能状態となりました（第三者閲覧は未確認）。NTTドコモではオンライン手続き画面の注釈欠落により、利用者同意を得ないまま約34万4,213回線分の電話番号とプラン名をAmazonへ提供していた規約不備が発覚しました。
\\[出典: note - @cosme・ムラウチ・ドコモで相次いだ個人情報事故。何が起き、利用者はどう対応すべき？\\] (https://note.com/solo_dev_jp/n/na6a3667cf965)

## 深掘り

###  認証基盤および管理APIの脆弱性と「信頼された権限」の悪用

####  管理インターフェースおよび認証APIにおける構造的欠陥
現代のサイバー攻撃において、攻撃者はWebアプリケーションの「正面」からではなく、APIエンドポイントや認証プロトコルのロジック不備を突き、一挙に最上位特権を獲得する手法を多用しています。
Cisco ISE（CVE-2026-76460）の事例では、管理REST APIにおける認証チェックが回避され、一ステップでroot権限の実行に直結しました。同様に、WSO2 API Manager（CVE-2026-5430）では未対応アルゴリズムで署名されたJWT（JSON Web Token）をシステムが正常として受理・承認してしまう不備が突かれ、偽造された管理者トークンによって全バックエンドAPIやシークレット情報へ未認証でアクセスされる試みが観測されています。
これらの攻撃で特筆すべきは、管理者権限を獲得した攻撃者が即座にシステム内部のアクセスログや監査ログを直接改ざん・消去（アンチフォレンジック）できる点です。そのため、単一アプライアンス内部のログ監視だけに頼る従来型のSOC運用は限界を迎えており、外部のシスログサーバーやネットワークパケット分析と組み合わせた多層的な監査が不可欠となっています。

####  初期パスワード管理とサードパーティ・コンプライアンス管理の死角
技術的な脆弱性にとどまらず、システムの初期設定や運用管理プロセスにおける「人間の死角」が深刻な侵害を招いています。
さくらインターネットの調査では、販売管理システム内部にレンタルサーバーやVPSの「初期パスワード」が平文（プレーンテキスト）で保存されていたことが露呈しました。現用パスワードへの変更を行っていないアカウントが存在する場合、データベースの流出がそのままサーバー領域への直接侵入に直結する構造的リスクを生み出していました。
また、フィンテック企業のRevolutにおけるデータ侵害事案では、攻撃者がインフォスティーラーで奪取したイタリア内務省の正規メールアカウントを使い、5ヶ月間にわたり「捜査機関からの公式な開示要請」を偽装して法的コンプライアンス窓口に送り続けました。Revolut側は自動化された公的要請プロセスに従って680件の高額顧客（暗号資産保有者等）のパスポートや財務データを偽調査官に提供し続けており、法的・規約的コンプライアンス手続きそのものが強力なソーシャルエンジニアリングの迂回経路として悪用された決定的な例となりました。

###  関連知識

####  用語解説
*   **CVE-2026-76460 (Cisco ISE Authentication Bypass)**：Cisco Identity Services Engine (ISE) の管理REST APIにおける認証制御不備の脆弱性。未認証のリモート攻撃者が細工したリクエストを送信することで管理画面の認証を完全に迂回し、root権限でOSコマンドを実行できる（CVSS 10.0）。
*   **JWTバイパス / 偽造管理者トークン (CVE-2026-5430)**：WSO2 API Manager等において、署名検証ロジックの欠陥により未対応・不正なアルゴリズムで作成されたJWTを受け入れてしまう脆弱性。攻撃者は任意クレーム（管理者権限等）を埋め込んだトークンを自作して管理者になりすますことができる。
*   **暗黙のURL制限（Security by Obscurity）の破綻**：GyazoなどのWebサービスで、複雑な画像ID（URL）のみを非公開画像のアクセス制御としている設計モデル。アップロードサーバーから画像メタデータが一括漏洩した場合、非公開画像のアクセスパス（URL）が直接暴露され、認証なしで誰でも閲覧可能になる構造的リスクを指す。

####  今後の展望
*   **管理インターフェースの完全隔離と「非保持化（データミニマイゼーション）」の義務化**：
    ネットワークアプライアンスやAPI基盤に対するゼロデイ攻撃の急増を受け、管理用REST APIや管理画面をパブリックインターネットから遮断し、インフラストラクチャアクセス制御リスト（iACL）や閉域網のみに制限する設定が標準化されます。また、さくらインターネットの平文初期パスワード問題や過去の流出事例を踏まえ、初期パスワードの保持を廃止する設計（発行後の即時破棄）や、不要になった過去の顧客データをシステム内に保持し続けないデータミニマイゼーションガバナンスが強く求められます。

## 結論
2026年9月中旬に顕在化した一連のインシデントは、攻撃者が企業の「正面の防壁」を突破するだけでなく、Cisco ISEのような認証・認可基盤、GyazoやさくらインターネットのようなWeb・販売管理インフラ、さらには公的法執行要請を偽装する運用プロセスといった「最も信頼されている管理システムや裏口」を集中的に狙っている実態を示しています。
経営層およびIT管理者は、システムに侵入されること（Assume Breach）を前提とし、すべての管理用APIやインターフェースの論理隔離、平文認証情報の完全排除、ログの外部暗号化保管、およびコンプライアンス・要請手続きにおける多要素検証プロセスの構築を速やかに実行すべきです。
