# CCSP (Certified Cloud Security Professional) 30日間学習計画
## ～クラウド環境における設計・運用・ガバナンスの全領域を横断し、セキュリティアーキテクトとしての判断力を鍛える～

本計画は、(ISC)²とCSA（Cloud Security Alliance）が共同認定するCCSP（Certified Cloud Security Professional）試験の6つのドメインを包括的に網羅します。CISA（監査視点）やAWS-SCS（技術実装視点）で培った知識を土台に、「クラウド環境全体のセキュリティアーキテクチャを設計・評価し、ビジネス要件と規制要件を満たすガバナンス体制を構築できる」実践的判断力を30日間で修得します。

<course_context>
CCSPの学習カリキュラムは、以下の6つのドメインを軸に構成されています。
1. クラウドのコンセプト・アーキテクチャ・設計 (Cloud Concepts, Architecture and Design): クラウドコンピューティングの基本概念、参照アーキテクチャ、設計原則、マルチテナンシー、クラウドサービスモデル（IaaS/PaaS/SaaS）およびデプロイメントモデル（Public/Private/Hybrid/Community/Multi-Cloud）。
2. クラウドデータセキュリティ (Cloud Data Security): クラウドにおけるデータライフサイクル管理、データ分類・ラベリング、暗号化（保管時・転送時・使用時）、DLP（データ損失防止）、データの発見・マスキング・匿名化、データ権限管理（IRM/DRM）。
3. クラウドプラットフォーム・インフラストラクチャセキュリティ (Cloud Platform and Infrastructure Security): 仮想化技術のセキュリティ、コンテナ・サーバーレスのリスク、ネットワークセキュリティ（SDN、マイクロセグメンテーション）、物理データセンター設計、ビジネス継続性・災害復旧計画。
4. クラウドアプリケーションセキュリティ (Cloud Application Security): セキュアソフトウェア開発ライフサイクル（SSDLC）、DevSecOps、API セキュリティ、OWASP Top 10、アプリケーションテスト（SAST/DAST/IAST）、WAF、サンドボックス。
5. クラウドセキュリティオペレーション (Cloud Security Operations): 物理・論理インフラの運用管理、ログ管理と監視、インシデント管理・フォレンジック、構成管理・パッチ管理、脆弱性管理、ゼロトラスト運用。
6. 法律・リスク・コンプライアンス (Legal, Risk and Compliance): プライバシー関連法規（GDPR、CCPA等）、クラウド契約・SLA評価、監査・認証（SOC 2、ISO 27001/27017/27018、CSA STAR）、eDiscovery、データ主権・越境データ移転。
</course_context>

<day_plans>
<day n="1">
テーマ: CCSPの全体像とクラウドコンピューティングの基本概念
内容:
- CCSPの6ドメイン構成と試験特性（250問・4時間・CBT）を概観し、CISA/AWS-SCSとの知識の重なりを確認する。
- NIST SP 800-145によるクラウドの定義（5つの特性・3つのサービスモデル・4つのデプロイメントモデル）を正確に理解する。
- クラウドの「5つの本質的特性」（On-demand Self-service, Broad Network Access, Resource Pooling, Rapid Elasticity, Measured Service）を具体例で整理する。
- 思考タスク: オンプレミスからクラウドへの移行によって「変わるリスク」と「変わらないリスク」を、CISAで学んだリスク評価の観点から対比・整理する。
</day>

<day n="2">
テーマ: クラウド参照アーキテクチャと責任共有モデル
内容:
- CSA（Cloud Security Alliance）のEnterprise Reference Architecture と NIST SP 500-292 Cloud Reference Architecture を比較理解する。
- IaaS/PaaS/SaaSにおける責任共有モデル（Shared Responsibility Model）の境界線を具体的に整理する。
- マルチテナンシーにおける論理的分離の技術的実現方式（ハイパーバイザ、コンテナ、ネームスペース）とリスクを学ぶ。
- 実践: 自社のクラウド利用状況（IaaS/PaaS/SaaS別）をマッピングし、責任共有モデルに基づいて「自社が担うべきセキュリティ統制」の一覧表を作成する。
</day>

<day n="3">
テーマ: クラウドセキュリティの設計原則
内容:
- セキュリティ・バイ・デザイン：Defense in Depth、Least Privilege、Zero Trust、Fail-Secure の各原則のクラウド適用。
- クラウドにおける暗号化戦略：保管時（At-Rest）、転送時（In-Transit）、使用時（In-Use）暗号化と鍵管理（BYOK, HYOK, KMaaS）。
- クラウドネイティブなセキュリティサービス（CASB, CWPP, CSPM, CNAPP）の概要と位置づけ。
- 思考タスク: CISAで学んだ「予防・発見・修正コントロール」の分類を、クラウドネイティブセキュリティツール（CASB, CSPM, CWPP）にマッピングし、各ツールの監査上の位置づけを考察する。
</day>

<day n="4">
テーマ: クラウドデータライフサイクルとデータ分類
内容:
- CSAデータセキュリティライフサイクル（Create → Store → Use → Share → Archive → Destroy）の各フェーズにおけるセキュリティ統制。
- データ分類（Data Classification）とラベリング：機密度レベル（Confidential/Internal/Public）の定義とクラウド環境での適用。
- データオーナーシップ：データ所有者（Data Owner）、データカストディアン（Data Custodian）、データプロセッサーの役割と責任。
- 実践: 具体的な業務データ（顧客PII、業務ログ、公開Webコンテンツ）をCSAライフサイクルの各段階に当てはめ、フェーズごとのセキュリティ要件を設計する。
</day>

<day n="5">
テーマ: クラウドにおけるデータ暗号化と鍵管理
内容:
- 対称鍵暗号（AES-256）と非対称鍵暗号（RSA, ECC）のクラウド適用シナリオ。
- 鍵管理のモデル：CSP管理鍵 vs 顧客管理鍵（BYOK: Bring Your Own Key）vs HYOK（Hold Your Own Key）の選定基準。
- HSM（Hardware Security Module）とクラウドKMSの役割と評価ポイント（FIPS 140-2/3認証レベル）。
- 思考タスク: BYOK環境において、鍵のローテーション・バックアップ・破棄の運用手順を設計し、鍵の紛失時に業務データがアクセス不能となるリスクへの対策を考察する。
</day>

<day n="6">
テーマ: データの発見・DLP・匿名化技術
内容:
- クラウド環境におけるデータディスカバリー（Data Discovery）の手法と、シャドーデータ（Shadow Data）のリスク。
- DLP（Data Loss Prevention）のクラウド実装：ネットワークDLP、エンドポイントDLP、クラウドDLPの連携。
- データマスキング（動的・静的）、トークナイゼーション、匿名化・仮名化の技術的差異とGDPR/プライバシー要件との関係。
- 実践: テスト環境にコピーされた本番データの漏洩リスクに対し、静的データマスキングとトークナイゼーションのどちらが適切かを要件（可逆性・参照整合性・パフォーマンス）に基づいて比較検討する。
</day>

<day n="7">
テーマ: データ権限管理とデジタル著作権管理
内容:
- IRM（Information Rights Management）/ DRM（Digital Rights Management）のクラウド適用。
- データの残留リスク（Data Remanence）：クラウド上でのセキュアなデータ削除の課題（暗号消去 Crypto-Shredding）。
- クラウドストレージにおけるオブジェクトレベルのアクセス制御とバケットポリシーの設計。
- 思考タスク: SaaSサービス解約時に、自社データの完全な削除をCSPに対してどのように検証・証明させるかの手順と、暗号消去（Crypto-Shredding）の有効性を考察する。
</day>

<day n="8">
テーマ: 仮想化セキュリティとハイパーバイザの保護
内容:
- Type 1 / Type 2 ハイパーバイザの構造差異と各攻撃面（VM Escape, Side-Channel Attack, VM Sprawl）。
- 仮想マシン（VM）のハードニング：ゴールドイメージ管理、スナップショット管理、VM間の分離制御。
- 仮想ネットワーク（VLAN, VxLAN, SDN）のセキュリティ設計とマイクロセグメンテーション。
- 実践: マルチテナントIaaS環境における「VM Escape攻撃」のリスクシナリオを作成し、ハイパーバイザレベルで適用すべきセキュリティ統制を5つ列挙する。
</day>

<day n="9">
テーマ: コンテナ・サーバーレス・マイクロサービスのセキュリティ
内容:
- コンテナ（Docker/Kubernetes）セキュリティ：イメージスキャン、ランタイムセキュリティ、Pod Security Policy/Standards。
- サーバーレス（FaaS）のセキュリティ課題：関数レベルの権限管理、Cold Start時の脆弱性、イベントインジェクション。
- マイクロサービス間の認証・認可（mTLS、サービスメッシュ、OAuth 2.0/OIDC）。
- 思考タスク: Kubernetes環境でCISA的な「職務分掌（SoD）」をどのように実現するか（Namespace分離、RBAC、Admission Controller等）を整理する。
</day>

<day n="10">
テーマ: クラウドネットワークセキュリティ
内容:
- SDN（Software-Defined Networking）のセキュリティアーキテクチャとコントロールプレーン保護。
- クラウドネットワーク制御：Security Group、NACL、PrivateLink/VPC Peering、Transit Gateway。
- DDoS防御：クラウドネイティブDDoS緩和サービスと、CDN/WAFによる多層防御。
- 実践: マルチVPC構成のクラウド環境におけるネットワークセキュリティアーキテクチャ図を作成し、通信フローごとのセキュリティ統制（暗号化・認証・ログ取得）を設計する。
</day>

<day n="11">
テーマ: クラウドにおけるビジネス継続性・災害復旧
内容:
- CISAで学んだBCP/DRP概念のクラウド特化：マルチリージョン冗長化、Cross-Region Replication、Availability Zone設計。
- クラウドDRの構成パターン：Pilot Light、Warm Standby、Multi-Site Active-Active のRTO/RPO比較。
- データレプリケーション戦略：同期 vs 非同期、RPOとレイテンシーのトレードオフ。
- 思考タスク: オンプレミスのDR（Hot/Warm/Cold Site）とクラウドDRパターンを対比し、クラウドDRのコスト優位性と残存リスク（CSP障害時の対応等）を評価する。
</day>

<day n="12">
テーマ: 物理データセンターセキュリティとCSP選定
内容:
- CSPデータセンターの物理セキュリティ評価：立地選定（自然災害・地政学リスク）、ゾーニング、環境制御（空調・消火・電源冗長）。
- CSP選定のデューデリジェンス：認証（ISO 27001/27017/27018, SOC 2, CSA STAR）の評価方法。
- ロックイン（Lock-in）リスクとポータビリティ戦略：マルチクラウド、コンテナ化、API標準化。
- 実践: CSP3社（AWS、Azure、GCP）の主要セキュリティ認証・コンプライアンスページを比較し、自組織の要件に基づくCSP選定チェックリストを作成する。
</day>

<day n="13">
テーマ: セキュアソフトウェア開発ライフサイクル（SSDLC）
内容:
- SSDLC（Secure Software Development Lifecycle）のフェーズと各段階のセキュリティ活動。
- 脅威モデリング手法（STRIDE、PASTA、Attack Tree）のクラウドネイティブアプリへの適用。
- セキュリティ要件の定義：OWASP ASVS（Application Security Verification Standard）を活用した要件の体系化。
- 思考タスク: CISAで学んだ「要件定義段階でのセキュリティ組込み不足リスク」を、SSDLCの各フェーズに対応するセキュリティゲートとして具体的に定義する。
</day>

<day n="14">
テーマ: DevSecOpsとCI/CDパイプラインセキュリティ
内容:
- DevSecOpsの原則：「Shift Left」セキュリティとセキュリティの自動化。
- CI/CDパイプラインにおけるセキュリティゲート：SAST、SCA（ソフトウェア構成分析）、コンテナイメージスキャン、IaCスキャン。
- シークレット管理：Vault、AWS Secrets Manager等によるクレデンシャルのセキュア管理。
- 実践: CI/CDパイプライン（例: GitHub Actions）にSAST・SCA・コンテナスキャンのセキュリティゲートを組み込んだワークフロー図を設計する。
</day>

<day n="15">
テーマ: APIセキュリティとWebアプリケーション保護
内容:
- API セキュリティ：認証（OAuth 2.0, API Key）、認可、レート制限、入力バリデーション。
- OWASP Top 10 (2021) および OWASP API Security Top 10 の主要脆弱性とクラウド環境での対策。
- WAF（Web Application Firewall）の設計・運用：ルールセット管理、偽陽性対応、ログ分析。
- 思考タスク: REST API公開時の脅威を OWASP API Security Top 10 に基づいて列挙し、各脅威に対するクラウドネイティブな緩和策（API Gateway、WAF、レート制限等）を設計する。
</day>

<day n="16">
テーマ: アプリケーションテストと脆弱性評価
内容:
- SAST（静的アプリケーションセキュリティテスト）、DAST（動的テスト）、IAST（インタラクティブテスト）の特性比較と併用戦略。
- ペネトレーションテストのクラウド環境における注意点：CSPへの事前通知要件、スコープ制限。
- バグバウンティプログラムとResponsible Disclosureポリシーの設計。
- 実践: クラウド上のWebアプリケーションに対するセキュリティテスト計画を作成し、SAST/DAST/IASTの適用フェーズと実施頻度を定義する。
</day>

<day n="17">
テーマ: サンドボックスとアプリケーション仮想化
内容:
- サンドボックス技術（ブラウザ分離、マイクロVM、コンテナベース分離）による不正コード実行の封じ込め。
- SaaS環境におけるカスタムコード実行リスク（サードパーティアドオン、マクロ、スクリプト）と制御手法。
- SBOM（Software Bill of Materials）の活用とサプライチェーンセキュリティ。
- 思考タスク: サプライチェーン攻撃（SolarWinds型・依存ライブラリの改ざん型）のリスクに対し、SBOMとSCAツールをどう組み合わせて防御・検知するかを設計する。
</day>

<day n="18">
テーマ: クラウドインフラの運用管理と構成管理
内容:
- Infrastructure as Code（IaC）：Terraform、CloudFormation等による構成管理とドリフト検出。
- 構成管理データベース（CMDB）のクラウド適用とリソースタギング戦略。
- パッチ管理：CSP責任範囲 vs 顧客責任範囲のパッチ適用戦略。
- 実践: IaCによるインフラ構成のセキュリティベースライン（CIS Benchmark準拠）を定義し、CSPMツールによるドリフト検出の運用手順を設計する。
</day>

<day n="19">
テーマ: ログ管理・監視・SIEM運用
内容:
- クラウドログの種類（コントロールプレーンログ、データプレーンログ、フローログ、アプリケーションログ）と保全要件。
- クラウドSIEM/SOAR：ログ集約、相関分析、自動対応プレイブックの設計。
- CISAで学んだ監査ログ評価の観点をクラウド環境に適用：ログの完全性（改ざん防止）、保持期間、アクセス制御。
- 思考タスク: マルチクラウド環境（AWS CloudTrail + Azure Monitor + GCP Cloud Audit Logs）のログを統合的に分析するためのSIEMアーキテクチャと、監査人がログの完全性を検証するための手順を設計する。
</day>

<day n="20">
テーマ: インシデント管理とクラウドフォレンジック
内容:
- クラウドにおけるインシデントレスポンスの特殊性：揮発性データの確保、CSPとの連携手順、スナップショット取得。
- クラウドフォレンジック：従来型フォレンジックとの差異（物理媒体へのアクセス不可、マルチテナント環境での証拠保全）。
- チェーン・オブ・カストディ（証拠の連続管理）のクラウド環境での担保方法。
- 実践: クラウド上のEC2インスタンスがマルウェアに感染したシナリオにおいて、証拠保全（メモリダンプ・ディスクスナップショット・ログ取得）から初期分析までのフォレンジック手順書を作成する。
</day>

<day n="21">
テーマ: 脆弱性管理とゼロトラスト運用
内容:
- クラウドにおける脆弱性管理プロセス：スキャン、優先順位付け（CVSS/EPSS）、修復、検証のサイクル。
- ゼロトラストアーキテクチャ（ZTA）の構成要素：SDP（Software Defined Perimeter）、マイクロセグメンテーション、継続的認証。
- CISA（米国サイバーセキュリティ・インフラストラクチャセキュリティ庁）のZero Trust Maturity Model の概要。
- 思考タスク: 従来の境界型セキュリティからゼロトラストへの移行ロードマップを3段階（初期・中期・成熟期）で設計し、各段階の主要施策とKPIを定義する。
</day>

<day n="22">
テーマ: IDaaS・IAMとフェデレーション
内容:
- クラウドIAMの設計原則：最小権限、ロールベースアクセス制御（RBAC）、属性ベースアクセス制御（ABAC）。
- IDフェデレーション：SAML 2.0、OAuth 2.0、OpenID Connect（OIDC）の仕組みと使い分け。
- 特権アクセス管理（PAM）：ブレイクグラスアカウント、JIT（Just-In-Time）アクセス、セッション記録。
- 実践: マルチクラウド環境における統合ID管理アーキテクチャを設計し、IdP（Identity Provider）からの認証フローとロールマッピングを図示する。
</day>

<day n="23">
テーマ: プライバシー関連法規とデータ主権
内容:
- GDPR（EU一般データ保護規則）の主要原則：合法性、目的制限、データ最小化、保存制限、越境データ移転の規制。
- CCPA（カリフォルニア州消費者プライバシー法）、APPI（日本の個人情報保護法改正）との比較。
- データ主権（Data Sovereignty）とデータローカライゼーション要件がクラウドアーキテクチャに与える影響。
- 思考タスク: グローバル展開企業がEU・日本・米国のデータを単一のクラウド環境で処理する場合、各法域のプライバシー要件を満たすデータフロー設計を検討する。
</day>

<day n="24">
テーマ: クラウド契約・SLA評価と法的リスク
内容:
- クラウドサービス契約のレビューポイント：データ所有権、準拠法、解約時のデータ返却・削除条項。
- SLA（Service Level Agreement）の評価：可用性保証、補償条件（Service Credit）、除外事項、SLO/SLI。
- eDiscovery（電子情報開示）：クラウドデータに対する訴訟保全命令への対応手順。
- 実践: 主要CSPの標準SLAを読解し、「顧客にとって不利な条項」を3つ以上特定し、交渉・緩和策を提案する。
</day>

<day n="25">
テーマ: クラウド監査と認証フレームワーク
内容:
- CSA STAR（Security, Trust, Assurance and Registry）のLevel 1（Self-Assessment）/Level 2（Third-Party Audit）/Level 3（Continuous Monitoring）。
- SOC 2 Type I / Type II のクラウドCSPに対する適用と、CISAで学んだSOCレポート読解スキルの活用。
- ISO 27017（クラウドセキュリティ）・ISO 27018（クラウドにおけるPII保護）の概要と監査ポイント。
